# webbeans
WebBeans
* This is an attempt to make a web UI framework that allows the user to write applications, in the spirit and style of Swing applications on the NetBeans Platform, but in only server-side Java and no JavaScript (unless they choose to). The end result should be a similar style development pattern as for NBP applications, but rendered in browser with HTML5/JavaScript.
* Inspiration comes heavily from the excellent work in the NetBeans Platform and will likely be guided by advice from that project as well.
