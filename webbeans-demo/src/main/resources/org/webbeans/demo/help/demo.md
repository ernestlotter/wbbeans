# The WebBeans demo

The demo module exercises the platform's components one window at a time:

- **Planets** — an explorer over a per-session solar system: rename, delete, drag, paste; double-click opens a
  planet window.
- **Form** — the input components with validation and a progress bar.
- **Dashboard** and **Moons** — charts over the planets, live and exportable.
- **Solar system 3D** — the planets in 3D: pick, drag the probe, fly to a planet.
- **Events** — every event the server receives.

Try <kbd>Ctrl</kbd>+<kbd>N</kbd> for a new planet, **Planets ▸ Scan the sky** for a cancellable progress
task, and **Tools ▸ Options** for the Options dialog.
