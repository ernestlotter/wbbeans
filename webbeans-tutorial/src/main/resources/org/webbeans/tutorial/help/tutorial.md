# Tutorial windows

The windows of the tutorial module follow the **User's Guide** (`docs/user-guide.md`):

| Window | Guide section |
|--------|---------------|
| **Hello** | §1 — a text field, a button and a label |
| **New contact** | §2–§5 — a validated form, a confirmation dialog, a notification and a progress bar |
| **Tasks** | §7–§8 — nodes in an `OutlineView`, popup, toolbar and shortcut actions |

## Tasks

- **Tools ▸ Add Task…** (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd>) asks for a title and adds a task.
- Select tasks and choose **Mark as Done** from the popup, the toolbar or the Tools menu; finished tasks are
  struck through.
- <kbd>F2</kbd> renames, <kbd>Delete</kbd> removes; the **Done** column is editable in place.
- **Tools ▸ Options ▸ Tutorial** has one setting, *Hide finished tasks* — see the Options chapter of the guide.

This page itself is `@HelpPage` number one of the guide's help chapter: press <kbd>F1</kbd> in the Tasks window
to come here, or open **Help ▸ Help Contents**.
