# Server Status

Administrators see the **Server Status** window (also **Window ▸ Server Status**): every session signed in to
the server, with the user, the address, the number of open tabs, the sign-in time, the last activity and the
language. The summary line counts sessions and tabs and shows the JVM's memory use. The list refreshes every two
seconds.

Right-click a session ▸ **End session** signs that user out of every tab after a confirmation; the Output window
logs it.

Administrators also get their own window arrangement with this window open at the bottom; rearranging it is
remembered separately from the ordinary layout.
