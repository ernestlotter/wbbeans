# Output

The **Output** window at the bottom collects messages from every tool: a file was saved, a part was picked,
the CPU is hot. Each line carries a time stamp and the tool that wrote it, for example `[files]`.

- Messages appear in **every browser tab** you have open — the window listens to your session, not to one tab.
- The window keeps the last 500 lines.
- **Edit ▸ Delete** (or the <kbd>Delete</kbd> key while the window is active) clears it.
- Warnings and errors are prefixed with their level.
