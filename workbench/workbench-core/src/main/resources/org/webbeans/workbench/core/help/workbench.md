# Welcome to the Workbench

The Workbench is the WebBeans sample application: a small set of tools that share one window, one login and
one set of settings.

| Window | What it does | Help |
|--------|--------------|------|
| **Files** | Browse and edit the files of your working directory | [Files and the editor](../../files/help/files.md) |
| **Dashboard** | Live charts of the server's load and traffic | [Dashboard](../../dashboard/help/dashboard.md) |
| **3D Viewer** and **Parts** | A turbine assembly with live sensor readings | [3D Viewer](../../viewer3d/help/viewer.md) |
| **Output** | Messages from every tool, in every browser tab | [Output](output.md) |
| **Server Status** | Who is signed in (administrators) | [Server Status](../../admin/help/admin.md) |

## First steps

1. Open a file: double-click `README.md` in the **Files** window. Edit it and press <kbd>Ctrl</kbd>+<kbd>S</kbd>.
2. Watch the **Dashboard** for a minute — the CPU chart spikes every 45 seconds and raises a notification.
3. Click a blade in the **3D Viewer**: the part is selected in the **Parts** tree and the Properties window.
4. Choose **Tools ▸ Options** to switch the theme or the language — see [Options](options.md).

## Accounts

Two demo accounts exist after the first start: `alice` (user and administrator) and `bob` (user), both with
the password `secret`. Administrators also see the **Server Status** window.

## Getting help

Press <kbd>F1</kbd> in any window for its page, or open **Help ▸ Help Contents**. The platform's own page,
[Getting around](help:platform), explains the window system.
