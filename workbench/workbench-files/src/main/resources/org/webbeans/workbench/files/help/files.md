# Files

The **Files** window shows your working directory on the server: every user has their own. It starts with a
few sample files (`README.md`, `notes.txt`, a `src` folder).

## Working with files

| Action | How |
|--------|-----|
| Open a file | Double-click it, or right-click ▸ **Open** |
| Create a file | **File ▸ New File…** (<kbd>Ctrl</kbd>+<kbd>N</kbd>) or the toolbar button; the file is created in the selected folder and opened |
| Create a folder | **File ▸ New Folder…** |
| Rename | Select the file and press <kbd>F2</kbd>, or edit the **Name** property |
| Delete | Select and press <kbd>Delete</kbd> (asks first) |
| Refresh | **File ▸ Refresh** (<kbd>F5</kbd>) re-reads the directory from the server |

The **Size** and **Modified** columns can be sorted by clicking their headers. The Properties window shows the
same values plus the file's location on the server.

Editing is described under [The editor](editor.md).
