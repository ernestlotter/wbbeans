# Parts

The **Parts** window lists the turbine's parts as a tree, sharing its selection with the [3D Viewer](viewer.md).

- Select a part to highlight it in the viewer and show its properties: kind, colour, position and — for
  sensors — the live temperature and status.
- Press <kbd>F2</kbd> (or edit the **Name** property) to rename a part; the viewer's labels follow.
- Sensors that run hot are shown in red.
